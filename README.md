## 💡 과제 소개 : 레거시 코드 리팩토링 플러스

레거시 코드란 나를 포함한 모든 개발자가 기존에 개발했던 코드를 말한다. 잘 작동되는 코드여도 오래된 기술을 사용할 수 있고,
현재는 사용되지 않는 코드들도 있다. 따라서 이러한 레거시 코드의 리팩토링을 통해 코드의 가독성과 유지보수성을 높이고, 성능을 개선하고, 변경에 대한 리스크를 줄여 
안정적인 서비스를 운영에 기여하는 것이 이번 과제의 목표이다.
<br/><br />

## 🚀 리팩토링 내용

### 에러 해결

    1. 일정 저장 API 호출할 때 발생한 Transaction 설정 문제 해결
    2. Controller 테스트가 정상적으로 동작하도록 수정
    


  ### 코드 추가

    1. User 정보에 nickname 컬럼 추가 및 JWT에서 유저의 닉네임을 추출하여 화면에 표시
    2. 일정 검색 시 weather와 수정일 기준으로 검색할 수 있도록 JPQL 수정
    3. 일정 새로 저장할 시, 일정을 생성한 유저가 담당자로 자동 등록될 수 있도록 수정
    4. 일정 제목, 생성일 범위, 닉네임으로 검색할 수 있는 기능 추가
    5. 매니저 등록 요청을 기록하는 로그 테이블 추가
    6. EC2, RDS, S3를 사용해서 프로젝트 관리 및 배포


    
  ### 코드 개선

    1. UserAdminController 클래스가 changeUserRole() 메소드 실행전에 동작하도록 AOP 수정
    2. CommentController 클래스의 getComments() API를 호출할 때 발생하는 N+1문제 해결
    3. JPQL로 작성된 일정 조회에서 findByIdWithUser를 QueryDSL로 변경
    4. Filter와 Argument Resolver를 사용했던 코드를 SpringSecurity로 변경
    5. 대용량 데이터 처리 조회 속도 개선
